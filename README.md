# Aluma Wellness Studio

Site estático de uma página (HTML único, com imagens e vídeo embutidos).

## Publicar na Vercel
1. Suba esta pasta em um repositório no GitHub.
2. Na Vercel: Add New > Project > importe o repositório.
3. Framework Preset: **Other**. Não precisa de build command nem output directory.
4. Deploy.
